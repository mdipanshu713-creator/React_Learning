### Simple Answer (Interview Style)

Suppose:

```javascript
count = 15

setCount(count + 1)
setCount(count + 1)
setCount(count + 1)
setCount(count + 1)
```

React does not update immediately.

All `setCount()` calls are collected together (**batched**).

Since `count` is still `15` during the whole function execution, React gets:

```javascript
setCount(16)
setCount(16)
setCount(16)
setCount(16)
```
Now React processes all these updates together and the final value becomes:

```javascript
16
```

Not:

```javascript
19
```

Because every call used the same old value `15`.

---

### Why `prevCount` Works

```javascript
setCount(prev => prev + 1)
setCount(prev => prev + 1)
setCount(prev => prev + 1)
setCount(prev => prev + 1)
```

React processes them one by one:

```text
15 → 16
16 → 17
17 → 18
18 → 19
```

Final value:

```javascript
19
```

### One-Line Interview Answer

> React batches state updates. `count + 1` uses the same old value every time, but `prevCount` gets the latest updated value, so multiple updates work correctly.
